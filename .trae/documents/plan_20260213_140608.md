## Codex 设置页面 i18n 汉化计划

### 需要汉化的内容

`SettingsCodexSection.tsx` 文件中有大量硬编码的英文文本，包括：

1. **标题和副标题**
   - "Codex" / "Configure the Codex CLI..."
   
2. **字段标签**
   - Default Codex path/args、Model、Reasoning effort、Access mode、Review mode 等

3. **按钮文本**
   - Browse、Use PATH、Clear、Run doctor、Update、Refresh 等

4. **帮助文本**
   - 各种说明文字

5. **诊断结果文本**
   - Codex looks good/issue detected、Version、App-server、Node 等

6. **选项值**
   - Read only、On-request、Full access、Inline、Detached 等

7. **占位符文本**
   - 各种 placeholder 文本

### 实施步骤

1. **更新中文翻译文件** (`src/i18n/locales/zh/translation.json`)
   - 在 `settings.codex` 命名空间下添加所有 Codex 设置页面的翻译

2. **修改组件文件** (`SettingsCodexSection.tsx`)
   - 将所有硬编码文本替换为 `t('settings.codex.xxx')` 调用
